# Loon 插件镜像

将多个上游去广告/功能增强配置转换并整理为 Loon 插件（`.lpx`），脚本全部本地化，不依赖原作者仓库。

- 使用：https://wfordawn.github.io/Rewrite/
- 插件清单：`index.json`
- 配置源：`wfordawn/loon-upstream-source`（私有，由 `sync.sh` 拉取）

## 目录

```
Loon/
├── AdBlock/      应用去广告
├── Function/     功能增强
├── Html/         网页增强
├── UnlockVip/    VIP 解锁
└── Scripts/      JS 脚本
docs/             网页界面 + 图标
```
